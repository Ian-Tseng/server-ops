# Security

Report vulnerabilities privately through GitHub's private vulnerability reporting for
this repository. Do not include credentials, private process arguments, or sensitive
workspace receipts in public issues.

Local Server Ops accepts only explicit local workspace adapters and credential-free
literal loopback HTTP health URLs. Version 0.1.2 has no certified mutation provider and
must not be used to bypass native process, supervisor, production, container, database,
or operating-system service controls.

Package verification rejects changed manifested files and untrusted GitHub install
metadata. Local receipts remain on the owner profile and are never uploaded automatically.
