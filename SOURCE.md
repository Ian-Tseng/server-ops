# Source and ownership

Local Server Ops is maintained by Yin-Yan Tseng through
[Ian-Tseng/server-ops](https://github.com/Ian-Tseng/server-ops).

The v0.3.0 release candidate extends the public v0.2.1 baseline. Its exact local source
and package bytes are bound by `skills/server-ops/manifest.json`, the accepted component
map, and the release-candidate test receipt. Those artifacts are pre-publication evidence,
not proof of a public release; published bytes are additionally bound by the immutable
release tag and GitHub release attestation.

External design sources and exact adopted/rejected patterns are listed in
[`source-ledger.md`](skills/server-ops/references/source-ledger.md). External text was
not copied.
